# 圖影工坊

純瀏覽器的**圖片＋影片**批次處理工具：**比例裁切 · 浮水印 · 縮放壓縮 · 轉格式**。

- 檔案全程在你的瀏覽器裡處理，**不會上傳到任何伺服器**
- 不需安裝；圖片功能手機、平板、電腦都能用
- 支援拖曳多個檔案或整個資料夾、批次處理、一次輸出多種比例

## 支援格式

| 類型 | 輸入 | 輸出 |
|---|---|---|
| 圖片 | JPG、PNG、WebP、GIF、BMP、HEIC | JPG、PNG、WebP、GIF（單張，256 色） |
| 影片 | MP4、MOV、WebM、MKV（含 H.264、H.265/HEVC、VP9、AV1 等，**以瀏覽器能解碼者為準**） | MP4（H.264）、MOV（H.264）、WebM（VP9）、AVI（MJPEG，檔案很大，上限約 2GB） |

> ⚠ **影片功能需使用 Chrome 或 Edge 電腦版**（需支援 WebCodecs）。Safari、Firefox、手機瀏覽器可能無法處理影片，但圖片功能照常可用。
> H.265/HEVC 能否讀取取決於你的電腦與瀏覽器的解碼支援（通常需要支援 HEVC 的顯卡或系統解碼器）。
> 影片處理時間取決於影片長度與電腦效能；聲音會保留（格式不相容時自動轉成相容編碼）。

## 功能

- **比例裁切**：1:1、2:3、3:2、1.91:1、4:5、9:16 與自訂比例；可複選一次輸出多個；預覽中可拖曳、縮放每個裁切框
- **浮水印**：九宮格定位、拖曳微調、大小/透明度/旋轉、浮水印圖庫（圖片與影片都能用）
- **尺寸縮放**：長邊上限、指定寬/高、百分比、指定寬×高
- **壓縮與格式**：圖片品質、檔案大小上限；影片位元率、幀率上限、檔案大小上限
- **檔名規則**：`{name}` `{ratio}` `{w}` `{h}` `{n}`（流水號）`{i}` `{date}` `{time}`
- **預設設定**：可儲存、載入、匯出/匯入，換裝置也能帶走
- **輸出**：Chrome / Edge 電腦版可直接存到你選的資料夾；其他瀏覽器自動下載（多個檔案打包 ZIP）

## 使用

直接開啟網頁即可。設定與浮水印圖庫存在你自己的瀏覽器裡（不同裝置/瀏覽器不共用，可用「匯出全部設定」帶走）。

## 部署到 GitHub Pages

1. 把這個資料夾的所有檔案（含 `js/vendor/`）放到一個 GitHub 儲存庫根目錄
2. 儲存庫 **Settings → Pages → Build and deployment**：Source 選 *Deploy from a branch*，Branch 選 `main`、資料夾 `/ (root)`
3. 稍等一兩分鐘，網址會是 `https://<你的帳號>.github.io/<儲存庫名稱>/`

## 在本機使用

不用網路也能用：下載後雙擊 `index.html` 即可。

## 使用的開源程式庫（放在 `js/vendor/`）

- [Mediabunny](https://mediabunny.dev)（MPL-2.0）：影片讀取、轉檔與封裝
- [gifenc](https://github.com/mattdesl/gifenc)（MIT）：GIF 輸出
- [heic2any](https://github.com/alexcorvi/heic2any)（MIT，內含 libheif）：HEIC 照片轉換
